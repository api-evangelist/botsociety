# Botsociety

> Botsociety is a tool to design, preview, and prototype chatbots and voice assistants. Its API lets applications retrieve the content of a design (messages, intents, variables) at runtime so bot content can change without a code redeploy. The product is winding down and the API host (app.botsociety.io) is presently unreachable; artifacts here are reconstructed from the official first-party npm client and public API docs.

## APIs
- [Botsociety API (OpenAPI)](https://raw.githubusercontent.com/api-evangelist/botsociety/refs/heads/main/openapi/botsociety-openapi.yml): 12 operations across Designs, Conversations, Messages, and Variables. Auth via user_id + api_key_public headers.

## Docs
- [API documentation](https://botsociety.github.io): Botsociety API documentation site.
- [Apiary reference](https://botsociety.docs.apiary.io/): endpoint reference.
- [Official npm client](https://www.npmjs.com/package/botsociety): `npm install botsociety`.
